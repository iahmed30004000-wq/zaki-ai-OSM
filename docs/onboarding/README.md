## خمس قواعد قبل أي سطر

1. لا push على `main`: فرع + PR + CI أخضر + مراجعة مستقلة.
2. لا دخول على الإنتاج ولا كتابة عليه، ولا `prisma migrate dev`، ولا مسح قاعدة.
3. المال (`computeCod` · `allocateDiscount` · `roundMinor` · `giftUnits`) يُستورد ولا يُنسخ؛ أي لمس للمال أو المخزون أو إنشاء الطلب بإذن المالك ومراجع حساب.
4. كل PR يبدأ بـ«تعريف الانتهاء»، وكل اختبار جديد يُكسر عن قصد مرة.
5. النشر بضغطة المالك وحده. أي ترحيل يندمج يتطبّق على الإنتاج بأول «Redeploy» (`docker-entrypoint.sh` يشغّل `prisma migrate deploy`).

المهام والخطة اليومية وخطة الطوارئ عند المالك بمساحة العمل (مشروع «zaki oms»)، مش بالمستودع.
